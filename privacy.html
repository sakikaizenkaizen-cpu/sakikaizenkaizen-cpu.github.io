プライバシーポリシー

「事務作業よさようなら」（以下「運営者」）は、Google Apps Script のツール「1to1-note（1to1人脈ノート）」（以下「本ツール」）における情報の扱いを、次のとおり定めます。

1. 本ツールが扱う情報

  • 利用者の Zoom アカウントにある面談の文字起こし
  • 利用者の Notion のデータベースに登録する内容（相手の名前・面談の要約など）
  • 利用者が設定する各サービスの接続用の鍵（API キーなど）
  • 本ツールを設置したスプレッドシートの内容

2. Google アカウントの情報の使い方

本ツールが Google に求める権限と、その使い道は次のとおりです。

  • 設置したスプレッドシートの読み書き：設定と処理の記録のため
  • スプレッドシートのメニュー・画面の表示：初期設定の操作のため
  • 外部サービスとの通信：Zoom・Notion・Anthropic（Claude）を呼び出すため
  • 定期実行の設定：新しい面談を自動で取り込むため
  • メールの送信：処理の失敗などを知らせるため
  • 本ツールが作成したファイルの利用：本ツールが作ったファイルだけを扱うため

Google のユーザーデータを、上記以外の目的で使うことはありません。広告への利用、販売、第三者への提供は行いません。Google API から受け取った情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

3. 情報の保存場所

  • 面談の内容と要約は、利用者本人の Google アカウント（スプレッドシート）と Notion の中に保存されます。運営者のサーバーには保存しません
  • 接続用の鍵は、そのスクリプトを実行する利用者本人だけが見られる場所（Google Apps Script のユーザープロパティ）に保存します

4. 外部サービスへの送信

要約を作るため、文字起こしの内容を Anthropic（Claude）の API に送信します。Notion への登録のため、要約した内容を Notion の API に送信します。各サービスでの情報の扱いは、それぞれのサービスのプライバシーポリシーに従います。

5. 運営者への送信

不具合の調査のため、処理の成否や版の番号などを運営者に知らせることがあります。この知らせには、相手の名前・会話の内容・鍵の値・Notion のページ名や URL を含めません。

6. 保守のための共有

利用者が希望して運営者にスプレッドシートを「編集」で共有した場合に限り、運営者は保守の目的に限って、そのスプレッドシートの内容を見て、直すことがあります。共有はいつでも利用者が外せます。

7. 情報の削除

利用者は、スプレッドシートと Notion のデータを削除することで、本ツールが扱った情報をいつでも削除できます。Google アカウントの権限は、Google アカウントの「サードパーティ製のアプリとサービス」から取り消せます。
